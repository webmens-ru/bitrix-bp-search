# Поиск по спискам значений в дизайнере БП Битрикс24

Добавляет строку поиска в выпадающие списки значений полей (условия, параметры активностей)
в дизайнере бизнес-процессов Битрикс24. Работает и в коробке, и в облаке (bitrix24.ru и др.).

## Что делает

- Списки с 8+ вариантами (id вида `id_field_...`) превращаются в поле с поиском.
- Печатаете «теле» — в списке остаются «Телеграм», «Билайн АТС 9282284349» и т.п.
- Оригинальный `<select>` остаётся в форме и скрывается — при сохранении БП Битрикс
  получает то же значение, что и раньше, ничего в портале не меняется.
- Новые условия («Добавить условие») подхватываются автоматически.

Управление: **↑ ↓** — навигация, **Enter** — выбрать, **Esc** — закрыть,
клик по стрелке справа — показать весь список.

Поиск по вхождению: запрос разбивается на слова, и каждое слово должно входить
в текст или значение пункта (порядок слов не важен). Примеры:
`билайн 9282` → «Билайн АТС 9282284349», `чат рас` → «Онлайн-чат - Онлайн чат РАС»,
`openline` → оба пункта со значением `*|OPENLINE`.

## Установка (2 минуты)

**Firefox — вариант 1: userscript (рекомендуется, проще всего):**

1. Установите Tampermonkey: https://addons.mozilla.org/ru/firefox/addon/tampermonkey/
2. Перетащите файл `bitrix-bp-search.user.js` в окно Firefox → Tampermonkey предложит установить.
3. Готово. Настройки — правкой констант в начале файла скрипта.

**Firefox — вариант 2: расширение (папка `firefox-extension`, архив `bitrix-bp-search-firefox.zip`):**

Firefox не даёт установить стороннее дополнение навсегда без подписи Mozilla, поэтому два пути:

- **Временная установка (для проверки):** откройте `about:debugging` → «Этот Firefox» →
  «Загрузить временное дополнение» → выберите `manifest.json` из папки `firefox-extension`.
  Расширение будет работать до перезапуска браузера. Настройки — там же через шестерёнку.
- **Постоянная установка:** файл `bitrix-bp-search-firefox.zip` загрузите на
  addons.mozilla.org в раздел самостоятельного распространения (нужна бесплатная
  учётка разработчика) — Mozilla подпишет дополнение, после чего оно ставится
  как обычное и работает в том числе на постоянной основе.

**Chrome/Edge — расширение (без Tampermonkey):**

1. Распакуйте архив `bitrix-bp-search-chrome.zip` (или используйте папку `chrome-extension` как есть).
2. Откройте `chrome://extensions` (в Edge: `edge://extensions`).
3. Включите «Режим разработчика» (переключатель справа вверху).
4. Нажмите «Загрузить распакованное расширение» и выберите папку `chrome-extension`.
5. Готово — иконка появится на панели, скрипт сам включится на страницах дизайнера БП.

**Chrome/Edge — вариант 2: userscript через Tampermonkey:**

1. Установите **Tampermonkey**: https://www.tampermonkey.net/ (кнопка «Get from Store»).
2. Откройте Tampermonkey → «Создать новый скрипт», удалите шаблон
   и вставьте всё содержимое файла `bitrix-bp-search.user.js`.
3. Сохраните (Ctrl+S). Всё — скрипт активируется на страницах дизайнера БП автоматически.

Или: перетащите файл `bitrix-bp-search.user.js` в окно браузера → Tampermonkey
предложит установить его одной кнопкой «Установить».

## Проверка без Битрикса

Откройте `test-page.html` — там скопирован ваш фрагмент верстки (поле «Источник»),
поиск работает так же, как будет в дизайнере БП.

Автотесты логики (нужен Node.js): `npm install jsdom && node test.js`.

## Поведение поля

- Значение «[не установлено]» не подставляется в поле текстом: поле остаётся пустым
  (плейсхолдер показывает «[не установлено] · начните ввод»), сразу можно печатать поиск.
- «[не установлено]» — обычный пункт списка: появляется в полном списке или по запросу «не ус».
- Выбор «[не установлено]» из списка снова очищает поле.

## Настройки

**В расширении:** страница настроек — значок расширения на панели Chrome (или
`chrome://extensions` → «Подробнее» → «Настройки расширения»). Параметр:

- **Поиск по вхождению каждого слова** (вкл. по умолчанию) — «билайн 9282» находит
  «Билайн АТС 9282284349». Выключите, чтобы искать строго по подстроке целиком.
  Применяется сразу после сохранения, без обновления страниц.

**В userscript-варианте:** правкой констант в начале файла:

| Параметр | По умолчанию | Что меняет |
|---|---|---|
| `MIN_OPTIONS` | 8 | Минимум вариантов в списке, чтобы включался поиск |

## Ограничения

- Действует на селекты дизайнера БП:
  - списки значений: id вида `id_field_*`;
  - списки самих полей («Поле документа»): name вида `field_condition_field_N`;
  на страницах `/bitrix/admin/bizproc_activity_settings.php`, `/bitrix/admin/bizproc_workflow_edit.php`
  и `/crm/configs/bp/*` (облако; скрипт запускается во всех фреймах, включая фрейм дизайнера).
- Кнопка «...» (вставка переменных {=Document:...}) не изменяется — это отдельное окно-дерево.

## Обновление

- **Расширение:** после замены файлов откройте `chrome://extensions` и нажмите иконку
  обновления (круговая стрелка) на карточке расширения, затем обновите страницу БП (F5).
- **Userscript:** откройте скрипт в Tampermonkey, замените текст, сохраните (Ctrl+S).
